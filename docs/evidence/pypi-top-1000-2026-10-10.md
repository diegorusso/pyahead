# PyPI top-1000 validation, 10 October 2026

The third run of the protocol in `docs/pypi-validation.md`. It measures two
changes since the 17 September record: the import-fallback reachability shape
(design §11.1), and the Python 3.15 curation, which added seven rules and
moved fifteen scheduled 3.15 events to released after 3.15.0 shipped on
9 October. The corpus is the same one the 17 September run used, so every
difference below is PyAhead's, not the ecosystem's.

- Prepared by an agent on 10 October 2026. **Awaiting approval by Diego

CPY0135's new removal did not fire on this corpus.

### Closed: `werkzeug`, CPY0205

`werkzeug/middleware/profiler.py:26` is `try: from cProfile import Profile` /
`except ImportError: from profile import Profile`. The known-import table
listed the `cProfile` module but not its `Profile` class, so the fallback
shape did not apply and the deprecated `profile` import was reported. `cProfile`
is built on `_lsprof`, compiled into every CPython build, so the attribute
meets the table's criteria. `dfbb7ad` adds it with a regression test; a harness
rescan of `werkzeug` reports no CPY0205 finding.

### The three open rows

Reasons as recorded in `docs/evidence/pypi-top-1000.md`, "Open rows":

- `future` — `libpasteurize/main.py:44` (CPY0027): the bound name is rebound
  later in the module; an oracle limitation.
- `future` — `future/backports/urllib/request.py:1590` (CPY0108): an
  `os.name == 'nt'` import, right on Windows and unobservable on this host.
- `passlib` — `passlib/utils/__init__.py:854` (CPY0008): `from crypt import
  crypt as _crypt` inside a `try`, where the alias coincides with a real
  attribute of `crypt`; an oracle limitation.

None is a PyAhead defect the reachability grammar can express, so none has a
fixture.

## Not adjudicable

Unchanged in kind from the 17 September record: `import-error` (74) and
`module-not-importable` (45) are largely CPython-tagged wheels that cannot be
installed under the interpreter an earlier-version probe needs. A
multi-interpreter wheelhouse would close them and is out of this record's
scope.
