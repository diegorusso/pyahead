# Security policy

Report suspected vulnerabilities privately through the repository's GitHub
Security Advisory **Report a vulnerability** flow. Do not include exploit
details, private repository data, access tokens, or other secrets in a public
issue.

Security fixes are provided for the newest published alpha only. Older alpha
versions may receive a documented workaround but are not guaranteed a patch.

PyAhead's trust boundaries, local-scan behavior, corpus retention policy, and
release supply-chain controls are documented in
[`docs/security-and-privacy.md`](docs/security-and-privacy.md).
